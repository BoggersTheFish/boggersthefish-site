## Boundary

This is not a broad NLP claim, not a general theorem-proving claim, not an external benchmark victory claim, not live TensionLM runtime integration, and not model confidence as proof authority.

The claim is narrower:

    TS-Reasoner exposes a verifier-first boundary where learned or language-model candidates can propose, but typed verifier channels decide.
